# 🎤 Автогенератор презентаций

Telegram-бот, который за минуты создаёт готовую презентацию в формате `.pptx` по одной только теме — без ручного набора текста и вёрстки.

---

## Проблема

Создание презентации с нуля занимает 30–60 минут: нужно придумать структуру, написать тезисы для каждого слайда, подобрать оформление. Когда презентация нужна «ещё вчера» — это критически много.

## Пользователь

- **Методисты** — быстро собрать материал к совещанию
- **Студенты** — подготовить доклад к семинару
- **Школьники** — сделать презентацию к уроку

Все говорят по-русски и работают в Telegram.

## Что делает бот

```
Пользователь → тема → число слайдов → (фото) → .pptx файл
```

1. `/start` — приветственное сообщение с инструкцией
2. Ввод темы презентации (до 500 символов)
3. Ввод числа слайдов (3–25) или «по умолчанию» (8–10)
4. Отправка фотографий (до 7 шт.) или пропуск
5. Подтверждение → генерация → отправка готового `.pptx`

---

## Формат результата

- **`.pptx`** — презентация в минималистичном чёрно-белом стиле (белый фон, чёрные заголовки, красные акценты, 16:9)
- **`.txt`** — текстовая версия всех тезисов (бонусом)

Шаблон не требует PowerPoint на стороне пользователя — файл открывается в MS PowerPoint, Google Slides, LibreOffice.

## Минимальный функционал (v1)

| Функция | Описание |
|---|---|
| Приём темы | Текст до 500 симв., кириллица |
| Выбор слайдов | 3–25 или «по умолчанию» |
| Приём фото | Альбомы (до 10 в одном сообщении) + одиночные, до 7 шт. |
| Лимит | 2 генерации в день на пользователя (сброс 00:00 МСК) |
| Генерация | Ollama Cloud API → структура → `.pptx` |
| Отмена | `/cancel` сбрасывает состояние в любой момент |

## Технологии

| Компонент | Стек |
|---|---|
| Telegram-бот | `aiogram` 3.x (async) |
| LLM | `minimax-m3:cloud` через Ollama Cloud API |
| Сборка `.pptx` | `python-pptx` |
| HTTP-клиент | `httpx` (async) |
| Хранилище | `aiosqlite` (FSM + счётчики) |
| Конфигурация | `pydantic-settings` |
| Логирование | `loguru` |
| Python | 3.11+ |

## Быстрый старт

### 1. Клонирование

```bash
git clone https://github.com/kateridzzze/generatepresentation_bot.git
cd generatepresentation_bot
```

### 2. Виртуальное окружение

```bash
python -m venv .venv
source .venv/bin/activate        # Linux/macOS
.venv\Scripts\activate           # Windows
```

### 3. Зависимости

```bash
pip install -r requirements.txt
```

### 4. Переменные окружения

```bash
cp .env.example .env
# Заполните .env:
#   TELEGRAM_BOT_TOKEN=...
#   OLLAMA_API_KEY=...
```

| Переменная | Обязательно | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | ✅ | Токен Telegram-бота от @BotFather |
| `OLLAMA_API_KEY` | ✅ | API-ключ Ollama Cloud |
| `OLLAMA_MODEL` | Нет | Модель (по умолчанию `minimax-m3:cloud`) |
| `OLLAMA_BASE_URL` | Нет | URL Ollama API (по умолчанию `https://ollama.com/api`) |
| `OLLAMA_TIMEOUT` | Нет | Таймаут в секундах (по умолчанию 60) |
| `DAILY_GENERATION_LIMIT` | Нет | Лимит генераций/день (по умолчанию 2) |
| `TZ` | Нет | Часовой пояс (по умолчанию `Europe/Moscow`) |
| `LOG_LEVEL` | Нет | Уровень логов (по умолчанию `INFO`) |

### 5. Запуск

```bash
python bot.py
```

## Архитектура

```
Telegram User ──► aiogram 3 (Dispatcher, FSM)
                        │
          ┌─────────────┼─────────────┐
          ▼             ▼             ▼
    SQLiteStorage   OllamaClient   pptx_builder
    (FSM, counters)  (LLM API)    (python-pptx)
```

### Структура файлов

```
├── bot.py                 # Точка входа
├── config.py              # Загрузка настроек из .env
├── app/
│   ├── handlers/
│   │   ├── start.py       # /start, /help, /cancel
│   │   ├── topic.py       # Приём темы и числа слайдов
│   │   ├── photos.py      # Приём фото, сборка презентации
│   │   └── fsm.py         # FSM-состояния
│   ├── services/
│   │   ├── ollama_client.py  # Клиент Ollama Cloud
│   │   └── pptx_builder.py   # Сборка .pptx
│   ├── storage/
│   │   └── sqlite.py      # FSM + счётчики генераций
│   └── utils/
│       ├── logging.py     # loguru setup
│       └── validators.py  # Валидация ввода
├── tests/                 # Unit-тесты
├── .env.example           # Шаблон переменных окружения
└── requirements.txt
```

## Сценарий работы

```
/start
  ▼
WAITING_TOPIC  ◄── пользователь присылает тему
  ▼
WAITING_SLIDES_COUNT  ◄── пользователь указывает число слайдов
  ▼
WAITING_PHOTOS  ◄── пользователь шлёт фото или «без фото»
  ▼
CONFIRM_GENERATION  ◄── бот показывает сводку и спрашивает «запустить?»
  ▼
GENERATING  ──► Ollama API ──► .pptx ──► отправка пользователю
  ▼
IDLE  (счётчик инкрементирован, FSM очищен)
```

## Лимиты

| Параметр | Значение |
|---|---|
| Генераций/день | 2 (сброс 00:00 МСК) |
| Слайдов | 3–25 |
| Фото | ≤ 7, каждое ≤ 10 МБ |
| Размер `.pptx` | ≤ 50 МБ |
| Timeout LLM | 60 с (retry 1 раз) |
